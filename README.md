## 🚀 Project Overview

This project analyzes retail sales data using Python to discover
patterns, trends, customer behavior, and product-level insights.

The analysis covers the complete workflow from **data loading and
cleaning to exploratory data analysis and visualization**.

---

## 🧰 Tech Stack

| Tool | Purpose |
|------|---------|
| 🐍 Python | Core analysis |
| 🐼 Pandas | Data cleaning & manipulation |
| 🔢 NumPy | Numerical operations |
| 📊 Matplotlib | Data visualization |
| 🎨 Seaborn | Statistical visualization |
